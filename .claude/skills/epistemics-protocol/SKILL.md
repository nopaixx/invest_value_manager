# Epistemics Protocol v1.0

> Loaded in session calibration. Three checks. No checklists of checklists.
> Created: Session 111, 2026-02-22. Origin: Epistemics Overhaul v2.

---

## 1. Edge Test (before any BUY)

Two questions:
- "What do I know that the market doesn't?" → If answer is vague → no edge → WATCHLIST, not BUY
- "What would falsify this thesis?" → If can't answer → unfalsifiable → don't buy

## 2. Omission Test (every session with cash >25%)

- "What is the BEST thing I could buy TODAY at market price?"
- "Why am I NOT buying it?"
- If reason is process (waiting for DA, need more analysis, entries unrealistic) → Error #58

## 3. Path Dependency Test (quarterly — every 30 sessions)

- "If I started from zero today, would I own this position?"
- "Am I holding because of thesis or because of sunk cost / organizational inertia?"
- If >40% of current positions would NOT be in the zero-base portfolio → investigate why they're still held

---

**Design principle:** Questions force thinking. Checklists enable autopilot. Three tests, each is a question.
