# Simon Property Group (SPG) — Análisis Completo

## Resumen Ejecutivo

**Simon Property Group** (NYSE: SPG) es el mayor REIT de centros comerciales del mundo. ~200 propiedades premium, $50B market cap, 96.4% ocupación.

**Veredicto: WATCHLIST — no comprar ahora.** Buen negocio pero caro.

| Métrica | Valor |
|---------|-------|
| Quality Score | 72/100 (Tier B) |
| Precio actual | ~$190 |
| Fair Value | $158 |
| Precio de entrada | $140 (-26% de aquí) |
| E[CAGR] esperado | 13.3% (debajo de nuestro mínimo 15%) |
| Moat | WIDE — localizaciones irreemplazables |
| Dividendo | ~5-6% |
| Deuda | $29.2B (normal para REIT) |

## ¿Por qué no compramos?

1. **Está caro.** A $190 no hay margen de seguridad. Necesitamos $140 para que tenga sentido.
2. **E[CAGR] insuficiente.** 13.3% está por debajo de nuestro mínimo de 15% para Tier B.
3. **Sin catalizador claro** para que baje un 26%.

## ¿Por qué es interesante?

1. **Moat WIDE** — nadie puede construir otro mall premium al lado del suyo. Localizaciones únicas.
2. **96.4% ocupación** — casi lleno. Los inquilinos no se van.
3. **Dividendo ~5-6%** — genera income mientras esperas.
4. **Superviviente** — sobrevivió al "death of malls" de 2017-2020 y al COVID. Los débiles murieron, Simon se quedó con el mercado.

## ¿Qué haría que comprase?

- Precio cae a $140 (recesión, crisis inmobiliaria)
- O E[CAGR] sube por mejora de crecimiento orgánico

## Riesgos principales

- **E-commerce** sigue creciendo — presión secular sobre retail físico
- **$29.2B de deuda** — si suben mucho los tipos, el coste de financiación sube
- **Recesión** = menos gasto del consumidor = menos ventas de inquilinos = riesgo de vacantes
- **Oil a $100+** = menos driving trips a los malls

## El Devil's Advocate (lo que puede ir mal)

El análisis adversarial encontró: crecimiento probablemente sobreestimado, no tenemos ventaja como inversores (todo Wall Street lo cubre), y el precio de entrada es demasiado alto. Redujo el fair value de $160 a $158.

## Smart Money

- Vanguard, BlackRock, State Street son los mayores holders (indexados, no señal)
- Insiders: David Simon (CEO) posee ~$600M+ en acciones — skin in the game
- Short interest: bajo (~2-3%) — los bears no apuestan fuerte contra SPG

## El Proceso

Cada empresa pasa por 4 fases con agentes especializados:

1. **R1 — Análisis** (3 agentes): ¿es buen negocio? ¿a qué precio compraríamos?
2. **R2 — Devil's Advocate** (1 agente): intenta destruir la tesis. Busca razones para NO comprar.
3. **R3 — Resolución**: ¿quién tiene razón, el bull o el bear?
4. **R4 — Comité** (10 requisitos): ¿cumple TODO para comprar?

El Devil's Advocate históricamente reduce los fair values un 17% de media. Sin él, pagaríamos de más por casi todo.
